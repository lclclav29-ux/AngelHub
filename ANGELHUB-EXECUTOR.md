# Angels Hub — #1.01 Reference Edition

Тёмно-бордовое меню по предоставленному референсу: боковая навигация, поиск сверху, тонкие разделители, две колонки карточек и анимированные переключатели. Поиск фильтрует разделы по русским/английским названиям функций; очистка возвращает навигацию. Без сторонней UI-библиотеки.

## Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/lclclav29-ux/AngelHub/angelhub-build-1.01/AngelHub.executor.lua"))()
```

Ключ: `Artur` (с заглавной A). Это локальный экран входа; ключ виден в исходниках и не обеспечивает серверную защиту.

Все функции первоначально выключены. Вкладки: движение, визуал, телепорт. ESP переиспользует объекты и ограничен 24 игроками; полёт использует конечные значения силы. `RightShift` или `AH` скрывают/показывают меню. `End`, `OFF` или «ОТКЛЮЧИТЬ СКРИПТ» полностью отключают обработчики, удаляют эффекты, останавливают голос и восстанавливают настройки персонажа и камеры. Для повторного запуска выполни загрузчик ещё раз.

## Голос

После правильного ключа воспроизводится «Приветствуем в ангелс хаб». Запись синтезирована локально eSpeak NG, русским голосом с женским вариантом `ru+f3`; это искусственная озвучка, не запись диктора. Файл: `assets/welcome-ru.ogg` (около 2 секунд).

Для этой записи нужны executor-функции `writefile` и `getcustomasset` (либо `getsynasset`). Скрипт скачивает Ogg по HTTPS, проверяет заголовок и размер, затем сохраняет `AngelHubWelcome_1_01_Red.ogg` в файловом пространстве executor. При отсутствии поддержки аудио меню остаётся доступным с текстовым приветствием. Можно задать разрешённый Roblox Audio ID в `GREETING_AUDIO_ID` вместо локального файла.

## Проверка и ограничения

Синтаксис проверен Lua-парсером. В имитации Roblox API проверены неверный/верный ключ, голос и его остановка, скорость, прыжок, ограничение и переиспользование ESP, полёт, отключение всех обработчиков и отключение до загрузки персонажа. Файл Ogg проверен ffprobe. Реальный Roblox и конкретный executor в этой среде недоступны; устранение нативного краша и совместимость не подтверждены. Сервер игры может переопределять функции персонажа.
